# Rare Oud QA Checklist

## تشغيل أساسي
- [ ] `npm install` داخل backend و frontend.
- [ ] إنشاء قاعدة MySQL وتشغيل `database/schema.sql`.
- [ ] نسخ `.env.example` إلى `.env` وتعبئة القيم.
- [ ] تشغيل `npm run seed:admin` ثم `npm run seed:data`.
- [ ] فتح `/api/health` والتأكد من `ok=true`.

## Auth & Security
- [ ] التسجيل لا يقبل بريدًا خاطئًا أو كلمة مرور ضعيفة.
- [ ] تسجيل الدخول يرجع JWT فقط بعد بيانات صحيحة.
- [ ] مسارات الأدمن ترفض المستخدم العادي وغير المسجل.
- [ ] رفع الصور يرفض الملفات غير الصورية والحجوم الكبيرة.
- [ ] لا توجد أسرار داخل الكود أو Git.

## Storefront
- [ ] العربية RTL هي الافتراضية.
- [ ] الإنجليزية LTR تغيّر الاتجاه والخطوط والنصوص.
- [ ] Light/Dark يعملان على كل الصفحات.
- [ ] المنتجات تعرض السعر، الصور، التوفر، التصنيف، والوسائط.
- [ ] البحث والفلترة يعملان مع السعر، الحالة، التصنيف، التوفر، البلد، والخشب.
- [ ] نموذج طلب المنتج المباشر يعمل ويظهر في لوحة التحكم وحساب المستخدم.

## Admin
- [ ] `/admin` محمي.
- [ ] إدارة المنتجات: إنشاء، تعديل، حذف ناعم، صور متعددة، روابط Drive.
- [ ] إدارة التصنيفات والمخزون والطلبات والمستخدمين والتقييمات.
- [ ] تعديل Hero/About/Policies/Settings يظهر في الواجهة.
- [ ] رقم واتساب وروابط التواصل قابلة للتعديل من الإعدادات.

## Mobile & UX
- [ ] Navbar مناسب للموبايل.
- [ ] البطاقات لا تنكسر على الشاشات الصغيرة.
- [ ] الأنيميشن ناعم ولا يمنع الاستخدام.
- [ ] حقول النماذج سهلة الاستخدام باللمس.
